### 1. 📖 Sobre o site e utilidade

O **Colégio Saber** é um projeto de site institucional completo, criado para apresentar os serviços de uma escola de forma profissional e clara na internet.

**Utilidade e objetivo:**
- Servir como principal canal de captação de alunos para pais e responsáveis.
- Centralizar informações essenciais como cursos, corpo docente, valores, processo de matrícula e contato.
- Passar credibilidade e modernidade para a instituição, com um design limpo e responsivo que funciona perfeitamente no celular, tablet e computador.
- Projeto ideal para portfólio Front-End, pois resolve um problema real de negócio.

**Páginas desenvolvidas:**
`Home` | `Sobre Nós` | `Cursos` | `Colaboradores` | `Preços` | `Matrículas` | `Contato`

### 2. 🛠️ Como foi o desenvolvimento

O site foi desenvolvido do zero, sem uso de frameworks, focando nos fundamentos do Front-End - exatamente o que foi aprendido na formação **Programador Front-End (SENAI - 180h)**.

O processo foi:
1.  **Estruturação:** Criação do mapa do site e de todas as páginas em HTML semântico.
2.  **Estilização:** Desenvolvimento de um layout 100% responsivo com CSS3, usando Flexbox e Grid para organização.
3.  **Interatividade:** Implementação de menu mobile, validações de formulário de matrícula e animações com JavaScript puro.
4.  **Deploy:** Publicação via GitHub Pages para acesso público.

### 3. 💻 Tecnologias Utilizadas

Este projeto foi construído utilizando as tecnologias base da web:

- **HTML5:** Utilizado para estruturação semântica de todo o conteúdo, garantindo SEO e acessibilidade.
- **CSS3:** Responsável por toda a parte visual, responsividade, animações e identidade visual do colégio.
- **JavaScript:** Usado para tornar o site dinâmico, com controle do menu responsivo e interações nos formulários de matrícula e contato.
